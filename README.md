# AWS Student Builder Challenge: Build Your Tech Superpower

> **Event Window:** October 27, 2026 – November 6, 2026 | **Status:** Live  
> **Challenge Type:** Student Innovation Challenge (Individual Builders)  
> **Hosting Platform:** AWS Builder Center  
> **Core Theme:** *"Build and deploy your personal portfolio website on AWS. It should tell your story, show your skills, and feature your creative tech superpower."*

---

## 📌 Executive Summary

The **AWS Student Builder Challenge** is an individual showcase for emerging student engineers, cloud architects, and builders. The mission is to design, develop, and deploy a production-grade personal portfolio website hosted live on **AWS Amplify Hosting**. Beyond a typical resume site, entries must highlight an inventive, fully functional **interactive "Tech Superpower"**—such as an interactive cloud architecture sandbox, an AI twin powered by Amazon Bedrock, an interactive terminal console, or an engineering mini-game.

## 🚀 Quick Launch (How to Use This Plan)

1. Read [`plan/01_CHALLENGE_OVERVIEW.md`](./plan/01_CHALLENGE_OVERVIEW.md) to understand the judging rubric and constraints.
2. Select an interactive superpower concept from [`plan/02_PORTFOLIO_CONCEPTS_AND_SUPERPOWERS.md`](./plan/02_PORTFOLIO_CONCEPTS_AND_SUPERPOWERS.md).
3. Follow the code blueprints in [`plan/INTERACTIVE_WIDGET_BLUEPRINTS.md`](./plan/INTERACTIVE_WIDGET_BLUEPRINTS.md) to implement your interactive superpower.
4. Deploy to AWS Amplify Hosting following [`plan/04_AWS_AMPLIFY_AND_SERVICES_GUIDE.md`](./plan/04_AWS_AMPLIFY_AND_SERVICES_GUIDE.md).
5. Prepare your demo video and submission text using [`plan/06_SUBMISSION_AND_DEMO_GUIDE.md`](./plan/06_SUBMISSION_AND_DEMO_GUIDE.md).
