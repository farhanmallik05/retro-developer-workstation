## 🎨 2. Submission Narrative & Concept

### Design Philosophy: Tactical Telemetry & CRT Terminal (FM-OS v4.2)
Unlike generic corporate portfolio templates, this website is conceived as a high-density, mechanical developer workstation. Evaluators are placed directly inside an operational cloud command terminal:
1. **Visual Language:** Dark obsidian substrate (`#080C14`), CRT scanlines simulation (toggleable via the top bar), green phosphor glows (`#10B981`), amber warning accents (`#F59E0B`), and mechanical monospace typography (`JetBrains Mono`).
2. **Interactive Command Shell (`visitor@aws-portfolio:~$`):** Evaluators can interactively execute commands like `help`, `bio`, `skills`, `projects`, `resume`, `curl`, `aws`, `sudo hire` (easter egg with confetti), and `matrix` (falling digital code rain).
3. **In-Browser Cloud Architecture CAD Sandbox:** Allows evaluators to select Well-Architected AWS patterns (`Global Edge Static Delivery`, `Serverless REST API`, `Bedrock GenAI Multi-Agent Pipeline`), compute live monthly hosting budgets, validate architectural completeness, and synthesize copyable AWS CDK v2 TypeScript and CloudFormation YAML templates on the fly.
4. **Bedrock AI Twin Avatar:** Evaluators can interview an AI avatar grounded on Claude 3.5 to inquire about distributed systems bugs, AWS serverless trade-offs, and engineering philosophy with sub-300ms latency.
5. **Real-World Engineering Dossiers:** Showcases production-grade engineering artifacts:
   - **EcoRoute:** Clean energy & EV geospatial navigator calculating routes across 45,000+ stations.
   - **CloudOps Swarm:** Autonomous multi-agent SRE incident triage reducing MTTD from 45 minutes to 28 seconds.
   - **Resilient Order Hub:** Fault-tolerant 5,000 TPS transaction processor with zero dropped orders under chaos fault injection.
